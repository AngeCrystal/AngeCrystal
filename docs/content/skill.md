## 正在翻阅的手册

```text
~/notes/
├── os/          processes · memory · concurrency
├── systems/     abstractions · architecture
├── agents/      tools · feedback · execution
└── graphics/    pixels · shaders · rendering
```

这是我感兴趣、想继续探索的方向，不是一张熟练度排行榜。

### 从程序往下看

操作系统和系统设计吸引我的地方，是它们藏在日常使用的工具下面：一个程序怎么运行，不同部分如何配合，抽象最终又落在什么地方。

### 从模型走向行动

AI 和 Agent 则把问题带到另一端：如何使用工具、接收反馈，并把一次输出接到真正的任务上。`/patchpilot` 是这个方向上的一个小实验。

### 从代码变成画面

`/mini-renderer` 用 C++ / OpenGL 从基础图形开始。它给这些探索多了一种很直观的反馈：写下的代码，最后会成为屏幕上的像素。

比起罗列一长串工具名，我更想留下可以打开、运行、继续修改的东西。
