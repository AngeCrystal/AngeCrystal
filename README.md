### ✦ 关于我 · Behind the screen

你好，我是 **AngeCrystal**。我喜欢追问技术背后的「为什么」，也喜欢在代码、故事和游戏之间发现新的可能。

我对 **操作系统、系统工程、AI 与 Agent** 很感兴趣：从程序如何运行，到系统如何协作，再到智能体如何使用工具、完成任务。这里记录我的探索，也存放一些由好奇心驱动的小作品。

### ⌘ 探索方向 · Current orbit

| 方向 | 想继续深入的问题 |
| :--- | :--- |
| **OS & Systems** | 从抽象到底层：进程、内存、并发与系统设计。 |
| **Agents & AI** | 从模型到行动：工具调用、执行反馈与可靠的工作流。 |
| **Build & Experiment** | 用小项目理解大概念，把想法变成可以运行的东西。 |
