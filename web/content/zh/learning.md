## 代码跑了，然后呢？

在最近的项目里，我在尝试把两件事分开记录：程序有没有实现，以及我有没有理解它。

Java 学习项目把工程进度和学习练习分别记录。一个接口能返回结果，是工程上的一步；能够解释请求怎么走到这里、改一个条件会发生什么，还需要自己练习。

### 把任务缩到可以检查

PatchPilot 按小阶段增加能力，再审阅实现、修改问题、重新检查。主页也是先部署能用的版本，然后慢慢补充内容和交互。

### 留下下一次能接上的记录

我会借助 Markdown 保存任务、阶段说明和进度。这样隔一段时间回来，不必只靠记忆猜测“上次做到哪了”。

这也是这个终端背后的想法：每条命令打开一小页，内容可以随着实践继续修改。

想看具体的两条路线，可以输入 `/patchpilot` 或 `/stockflow`。
