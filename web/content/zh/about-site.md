## 为什么这里是一个终端？

起初，这个主页有封面、兴趣标签和项目表格。它能介绍我，但读起来更像一张说明书。

我更想做一个可以慢慢发现内容的地方：不把所有爱好和技术方向一次铺开，而是让访客输入 `/whoami`、`/hobby` 或 `/projects`，自己决定下一步看什么。

于是，GitHub Profile 留下简短介绍和入口，真正的交互放在独立网页里。封面的水晶工坊，则保留在 GitHub 主页上。

### 它实际上怎么工作？

这是一组本地命令与 Markdown 文件的组合。网页按命令读取对应内容，没有 AI 对话，也没有连接到我的电脑或真实 shell。

会话只在当前页面里保留，刷新就会重置。现在由 GitHub Pages 托管。
