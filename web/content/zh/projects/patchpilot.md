## PatchPilot

一个用 Python 构建的编码智能体实验。我想把“模型建议改代码”接成一条可以检查的执行流程。

```text
读取 → 提案 → 差异预览 → 批准 → 写入 → 测试与结果
```

模型提出修改，宿主计算差异并检查执行条件。批准对应具体的预览；写入前还需要确认文件状态，避免把旧预览当成当前事实。

随着迭代，实验逐渐加入了工具注册与模式边界、会话上下文压缩，以及局部替换、新建文件等编辑方式。

我尤其在意失败时能否说清楚发生了什么。文件已经写入而测试失败，与完全没有执行修改，是两种不同结果。项目仍有实验性的限制，例如多文件写入不提供原子事务或自动回滚。
