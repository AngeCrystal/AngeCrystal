## StockFlow · 起步中的业务开发练习

我想补上从页面到数据库的业务开发经验，于是开始了一个采购、库存与销售管理的学习项目。

目标路线是 React 页面 → Java / Spring Boot 接口 → SQL 与事务。相比只把功能接起来，我也想理解业务状态如何变化、数据应该由哪一层负责。

### 已走到哪一步

按 2026-10-02 的项目记录，已实现 Java 后端健康检查接口，并完成构建和实际 HTTP 检查。React 前端、数据库以及采购库存业务仍在后续计划中；这还不是可用的进销存产品。

项目按小阶段组织开发和练习，把“代码完成”和“学习理解”分别记录。关于这套学习节奏，可以继续看 `/learning`。
