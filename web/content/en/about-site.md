## Why is this a terminal?

At first, this homepage had a cover, interest tags and a project table. It introduced me, but it read more like a manual.

I wanted a place where things could be discovered slowly: instead of laying out every hobby and technical direction at once, visitors type `/whoami`, `/hobby` or `/projects` and decide for themselves what to look at next.

So the GitHub profile keeps a short introduction and an entrance, and the real interaction lives on its own web page. The crystal atelier on the cover stays on the GitHub profile.

### How does it actually work?

It's a set of local commands combined with Markdown content. The page reads the matching content for each command; there's no AI chat, and no connection to my computer or a real shell.

The session only lives in the current page, and resets on refresh. It's currently hosted on GitHub Pages.
