## StockFlow · An early business-app exercise

I wanted experience with the path from a page to a database, so I started a learning project around purchasing, inventory, and sales.

The planned route is React → Java / Spring Boot APIs → SQL and transactions. Alongside connecting the pieces, I want to understand how business states change and which layer owns the data.

### Where it stands

According to the project record dated 2026-10-02, a Java backend health endpoint is implemented, with a successful build and live HTTP checks. The React frontend, database, and purchasing and inventory features remain planned. This is not yet a usable inventory product.

Development and exercises are organized into small stages, with implementation and understanding tracked separately. More about that approach in `/learning`.
