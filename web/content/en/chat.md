## Where to start a conversation?

If you're not sure what to talk about, start with a specific question.

- **OS / Systems**: what's a problem you ran into lately that made you want to look one layer deeper?
- **Agent / AI**: what would you like an agent to do for you? Which step most needs a human's judgement?
- **Graphics**: is there a visual effect you'd like to implement yourself?
- **Board games**: which set of rules has felt interesting to you lately?
- **Anime / gacha games**: any story, character, art or music you'd recommend?

There's no need to polish the topic first. A question, a passing thought, or a project worth opening can all be a beginning.

This terminal has no chat or message feature of its own; these are just entry points for getting to know me.
